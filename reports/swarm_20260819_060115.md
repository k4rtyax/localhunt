## Findings

### 1. [HIGH] XSS via location.hash

- Location: `vuln.js:2`
- Category: client-side injection
- Reported by: xss-hunter
- Confidence: 0.90 | Verdict: unverified

```
document.getElementById("out").innerHTML = location.hash.slice(1);
```

**Impact.** The `location.hash` is a source that can be controlled by the attacker via the URL. The `innerHTML` sink is vulnerable to XSS when the `location.hash` contains malicious content. This allows an attacker to inject arbitrary HTML into the page.

**Fix.** Use a safe method to handle the hash, such as sanitizing the hash before setting it to `innerHTML` or using a different DOM manipulation technique that doesn't allow arbitrary HTML injection.
